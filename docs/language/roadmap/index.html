What changed

Conversion semantics are integrated.

VOID now treats conversion legality as a semantic fact that survives target typing, generic specialization, iterator/closure transformation, GC-sensitive managed results, exceptions, cleanup, and library compilation. Concrete specialization no longer gets to widen generic source after the fact; constraints prove the operation first, and lowering consumes that proof.

A foundation, not a cage.
