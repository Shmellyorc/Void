VOID uses optional analytics to understand how the website is found and which pages are useful.

Google Analytics

VOID uses Google Analytics 4 only after you choose Accept analytics. If you decline, Google Analytics is not loaded and your choice does not affect access to the website.

What analytics can measure

When enabled, analytics can report information such as pages viewed, scroll activity, outbound link clicks, file downloads, browser and device information, referring sites or campaigns, and approximate geographic information. Google Analytics may set cookies such as _ga to distinguish visits.

Why VOID uses it

The data is used to understand website traffic, learn which articles and documentation are useful, see where visitors are coming from, and improve the VOID website. VOID does not use this website analytics setup for advertising personalization.

Your analytics choice

Your choice is stored in your browser. You can reset it at any time and choose again.

Google Analytics is provided by Google. You can read Google's Privacy Policy for information about Google's data practices.
