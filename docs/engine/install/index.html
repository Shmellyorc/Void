Install VOID

From zero to a
working VOID project.

The official template is the recommended way to start. It creates the expected project structure and references so you begin with a known-good setup instead of rebuilding it by hand.

Requirement: .NET 10. Runtime graphics, platform, input, and audio dependencies are restored through Void.Engine.
VOID Engine and VOID Language: VOID Engine currently runs on C# and .NET. A VOID Language edition of the engine is planned alongside it. The C#/.NET edition will remain available, while the VOID Language edition is intended to follow the same game-facing APIs, concepts, and workflow as closely as practical. If you already know VOID Engine in C#, moving to the VOID Language edition should feel familiar rather than like learning a different engine.

Two language paths. The same VOID Engine philosophy.

Install the official template

Install Void.Templates from NuGet.

terminal
dotnet new install Void.Templates

Create your game

Create a new project in a new folder.

terminal
dotnet new voidgame -n MyGame
cd MyGame

Run it

Restore happens through the normal .NET workflow.

terminal
dotnet run

Why the template?

The template creates a complete runnable project with Program.cs, your main Game subclass, a Content/ folder, and a preconfigured project reference to Void.Engine.

Prefer the current folder?

terminal
mkdir MyGame
cd MyGame
dotnet new voidgame
dotnet run
