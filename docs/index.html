Why VOID

Two paths. One vision.

Different tools. A shared foundation.

VOID Engine and VOID Language are independent projects designed to work beautifully together. Use one, or both. Either way, the goal is the same: give game developers more control, less friction, and a foundation that gets out of your way.

VOID

Engine

A high-performance 2D game engine with a pluggable renderer, built for flexibility and control. Designed to scale from small prototypes to ambitious projects.

  • Fast and lightweight
  • Pluggable renderer architecture
  • Modern tooling and workflow
  • Built for 2D without forcing a workflow
Explore Engine

VOID

Language

A modern, C#-inspired language with its own compiler and runtime. Its working core combines a mature object model, deterministic lifetime, managed threads, recursive monitors and lock, condition waiting/signaling, Interlocked atomics, Volatile acquire/release access, cooperative stop-the-world GC, nested and readonly structs, rectangular arrays, closures and iterators, pattern matching and switch expressions, user-defined and constrained generic operators/conversions, inferred/constrained generics, extension methods, default/static interface methods, structured exceptions/finally, unsafe/native interop, native callbacks, and reusable native library output.

  • C#-inspired, developer-friendly syntax
  • Compiles to C
  • Direct C interoperability
  • Rich object model, delegates, events, and generics
