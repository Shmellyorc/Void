Engine + Language

Two paths. One vision.

VOID Engine and VOID Language are independent projects designed to work beautifully together. Use one, or both. Either way, the goal is the same: give game developers more control, less friction, and a foundation that gets out of your way.

VOID

Engine

A high-performance 2D game engine with a pluggable renderer, built for flexibility and control. Designed to scale from small prototypes to ambitious projects.

  • Fast and lightweight
  • Pluggable renderer architecture
  • Modern tooling and workflow
  • Built for 2D without forcing a workflow
Explore Engine

VOID

Language

A modern, C#-inspired language built for game development, with its own compiler and runtime. It keeps familiar high-level code while compiling through C to native binaries, and it owns the runtime pieces underneath features such as threading, GC, exceptions, and native interop.

  • Familiar C#-inspired syntax
  • Native builds through portable C
  • Compiler, runtime, GC, and tooling owned by VOID
  • Direct C interoperability

Key features

Built for the way you make games.

A growing set of tools and ideas designed around control, performance, and simplicity.

Pluggable Renderer

OpenGL is the built-in backend, not a hard boundary. Higher-level rendering stays backend-neutral so another renderer can fit later.

Familiar code, independent runtime

VOID keeps the parts of modern managed code that make game systems easier to express, while its own compiler and runtime handle the machinery underneath.

Native output through C

VOID lowers to portable C and uses the system toolchain to produce native programs without requiring the .NET runtime.

Simplicity First

Less framework friction and less unnecessary complexity.

Native C Interop

Cross the C boundary directly when game code needs native libraries or lower-level control. VOID libraries can expose stable native entry points too.

Compiler Tooling

The compiler answers the editor's questions too, so diagnostics, completion, navigation, and signatures stay aligned with real builds.
